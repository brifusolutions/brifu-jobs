## Frontend (Next.js + Tailwind)

### Setup

```bash
cd frontend
npm install
```

Optional environment config:

```bash
copy .env.local.example .env.local
```

### Run (dev)

```bash
cd frontend
npm run dev
```

Open `http://localhost:3000`.

### Pages

- `/dashboard`: stats + recent activity
- `/upload`: drag & drop PDF upload + processing
- `/results`: searchable/sortable table + Excel export
